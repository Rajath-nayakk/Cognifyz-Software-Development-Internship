## 🚀 Quick Start

### Prerequisites
Make sure you have Python 3 installed:
```bash
python --version
# or on Windows
py --version
```

### Running Level 1 – Task 1 (Number Guessing Game)
```bash
cd "Task-1-Number-Guessing-Game"
py game.py
py -m unittest test_game.py -v
```

### Running Level 1 – Task 2 (Number Pattern Generator)
```bash
cd "Level-1-Beginner/Task-2-Number-Patterns"
py patterns.py
py -m unittest test_patterns.py -v
```
